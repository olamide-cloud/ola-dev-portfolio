# Ola Dev Portfolio

A responsive dark-mode starter portfolio built with HTML, CSS and JavaScript.

## Run locally
1. Extract this folder.
2. Open `index.html` in your browser, or open the folder in VS Code.
3. For a local development server, use the VS Code Live Server extension.

## Personalise before publishing
- In `index.html`, replace `YOUR-EMAIL@example.com` with your real email.
- Replace the GitHub and LinkedIn profile links with your actual profile URLs.
- Add real screenshots and working live-demo/repository links for each project.
- Edit the About, skills, services and project descriptions so they accurately represent your current experience.
- Do not list a technology as a professional skill unless you can use it confidently.

## Publish
You can deploy the folder using GitHub Pages or import its GitHub repository into Vercel.
